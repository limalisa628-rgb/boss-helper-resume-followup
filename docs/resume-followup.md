# 本地规则与简历跟进

只处理启用后招聘者新发的明确索要。普通问候不触发；否定、矛盾、引用、英文版、Word、微信、邮箱或链接要求转人工。本版不使用 AI，不自动回答面试问题或接受录用。

匹配依据为账户、会话、岗位、显式绑定的文件版本和哈希，而非 HR 姓名。城市和固定底薪未知、多岗位无法定位、文件被替换时，不能自动发送。

发送前预留额度并锁定任务。刷新、断线或超时后先核对，不能自动重试。传输层确认、文字招呼、在线简历卡片或图片不等于正确 PDF 已发送。

每个原生提交动作前，重新检查持久化开关、启用周期、任务租约、绑定版本及当前会话；适配器还必须在其异步准备后调用授权检查。暂停／切换模式期间准备中的动作不能继续点击发送。已经提交到平台的动作不代表可以撤回。

生产默认适配器尚未验证，因此当前实际可用的是演练和任务逻辑。真实消息接入需要稳定目标标识、唯一匹配 PDF、平台发送权限与新业务回执；缺一项就保持关闭。

PDF 位于扩展后台 IndexedDB，不放入 BOSS 网站源数据库，也不通过原版主页面 comctx 桥暴露。工作台使用限定来源、限定方法的内部 runtime RPC；文件校验 SHA-256，列表仅传元数据，按需读取单个文件。

移除本地文件会取消相关未发送任务并移除绑定，保留历史发送／不确定记录及当天额度；不会撤回平台附件。发送中的文件不能直接移除。
